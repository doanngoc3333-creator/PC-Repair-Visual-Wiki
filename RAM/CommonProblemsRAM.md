## Common RAM Problems

### 1. Black Screen

**Symptoms**
- The computer turns on, but the screen stays black.
- The monitor shows no signal.
- The computer may beep or flash a DRAM warning light.

**Causes**
- RAM is loose or dirty.
- RAM is faulty.
- The RAM slot is damaged.

**Solutions**
- Reinstall the RAM.
- Clean the RAM contacts.
- Test one RAM stick at a time.
- Try another RAM slot.

---

### 2. High RAM Usage (Memory Leak)

**Symptoms**
- RAM usage keeps increasing.
- The computer becomes slow or freezes.

**Causes**
- A program uses too much RAM.
- A program fails to release memory.

**Solutions**
- Close the program using too much RAM.
- Restart the program.
- Update or reinstall the program.

---

### 3. Computer Fails to Start with Certain RAM Slots

**Symptoms**
- The computer starts with one RAM slot but fails with another.
- The computer fails to start with two RAM sticks.

**Causes**
- A RAM stick is faulty.
- A RAM slot is damaged.
- RAM sticks are installed in the wrong slots.

**Solutions**
- Test each RAM stick separately.
- Try different RAM slots.
- Check the motherboard manual.
- Replace faulty parts.

---

### 4. Blue Screen (BSOD)

**Symptoms**
- The computer suddenly crashes.
- A blue error screen appears.
- The computer restarts unexpectedly.

**Causes**
- RAM is faulty.
- RAM settings are unstable.
- A driver or program has an error.

**Solutions**
- Test RAM using MemTest86.
- Test each RAM stick separately.
- Reset RAM settings to default.
- Update drivers.
- Replace faulty RAM.
