# Documention about PC and laptop hardware for IT support

* An SSD (Solid-State Drive) is a modern computer storage device that uses integrated circuits and flash memory chips to store data persistently without any physical moving parts

## Types of SSD

### 1. Based on Form Factor and Interface

- 2.5-inch SATA SSD
- mSATA SSD
- M.2 SATA SSD
- M.2 NVMe SSD
- PCIe Add-in Card (AIC) SSD
- U.2 SSD
- U.3 SSD
- EDSFF SSD (E1.S, E3.S)

### 2. Based on NAND Flash Memory Type

- SLC (Single-Level Cell) — 1 bit per cell
- MLC (Multi-Level Cell) — 2 bits per cell
- TLC (Triple-Level Cell) — 3 bits per cell
- QLC (Quad-Level Cell) — 4 bits per cell
- PLC (Penta-Level Cell) — 5 bits per cell

### 3. Based on Interface and Protocol

- SATA SSD
- PCIe SSD
- NVMe SSD
- SAS SSD

### 4. Based on Usage

- Consumer SSD
- Enterprise SSD
- Data Center SSD
- Industrial SSD
- Portable External SSD
