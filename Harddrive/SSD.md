# Documention about PC and laptop hardware for IT support

* An SSD (Solid-State Drive) is a modern computer storage device that uses integrated circuits and flash memory chips to store data persistently without any physical moving parts

---

## Types of SSD

### 1. Based on Form Factor and Interface

- 2.5-inch SATA SSD
- mSATA SSD
- M.2 SATA SSD
- M.2 NVMe SSD
- PCIe Add-in Card (AIC) SSD
- U.2 SSD
- U.3 SSD
- EDSFF SSD (E1.S, E3.S)

### 2. Based on NAND Flash Memory Type

- SLC (Single-Level Cell) — 1 bit per cell
- MLC (Multi-Level Cell) — 2 bits per cell
- TLC (Triple-Level Cell) — 3 bits per cell
- QLC (Quad-Level Cell) — 4 bits per cell
- PLC (Penta-Level Cell) — 5 bits per cell

#### SATA SSD
- Uses flash memory instead of mechanical parts like an HDD and connects via the SATA III interface.
- Protocol: AHCI
- Max speed: ~550 MB/s

#### PCIe SSD
- Uses flash memory and connects via the PCIe interface.
- Protocol: AHCI or NVMe
- Max speed: Up to ~1,969 MB/s (PCIe 3.0 x2) or ~3,938 MB/s (PCIe 3.0 x4).

#### NVMe SSD
- Uses flash memory and connects via the PCIe interface.
- Protocol: NVMe
- Max speed: Up to ~3,938 MB/s (PCIe 3.0 x4) or ~7,877 MB/s (PCIe 4.0 x4).

#### SAS SSD
- Uses flash memory and connects via the SAS interface.
- Protocol: SAS
- Max speed: Up to ~1,200 MB/s (12 Gb/s SAS) or ~2,400 MB/s (24 Gb/s SAS).
### 4. Based on Usage

- Consumer SSD
- Enterprise SSD
- Data Center SSD
- Industrial SSD
- Portable External SSD
