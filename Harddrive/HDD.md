# Documentation about PC and laptop hardware for IT support

* An HDD (Hard Disk Drive) is a traditional computer storage device that uses rotating magnetic platters and read/write heads to store and retrieve data persistently. Unlike an SSD, an HDD contains mechanical moving parts.

---

## Types of HDD

### 1. Based on Form Factor and Interface

- 3.5-inch SATA HDD
- 2.5-inch SATA HDD
- PATA/IDE HDD
- SAS HDD
- SCSI HDD
- External USB HDD

### 2. Based on Recording Technology

- CMR (Conventional Magnetic Recording) — Writes data to separate, non-overlapping magnetic tracks.
- SMR (Shingled Magnetic Recording) — Overlaps magnetic tracks to increase storage density.
- PMR (Perpendicular Magnetic Recording) — Stores magnetic bits perpendicular to the platter surface.
- HAMR (Heat-Assisted Magnetic Recording) — Uses localized heating to increase recording density.
- MAMR (Microwave-Assisted Magnetic Recording) — Uses microwave assistance to improve magnetic recording density.

### 3. Based on Interface and Technology

#### SATA HDD*
- Uses rotating magnetic platters and connects via the SATA interface.
- Protocol: ATA/ATAPI.
- Interface speed: Up to 6 Gb/s (SATA III).
- Typical sequential transfer speed: ~100–250 MB/s.

#### PATA/IDE HDD
- Uses rotating magnetic platters and connects via the Parallel ATA interface.
- Protocol: ATA.
- Interface speed: Up to 133 MB/s (Ultra ATA/133).
- Typical transfer speed: ~20–100 MB/s, depending on the drive.

#### SAS HDD
- Uses rotating magnetic platters and connects via the Serial Attached SCSI interface.
- Protocol: SCSI.
- Interface speed: Up to 12 Gb/s (SAS-3) or 24 Gb/s (SAS-4).
- Typical sequential transfer speed: ~150–300 MB/s, depending on the drive.

#### SCSI HDD
- Uses rotating magnetic platters and connects via the Small Computer System Interface.
- Protocol: SCSI.
- Interface speed and transfer performance depend on the SCSI generation.
- Commonly found in older servers and enterprise storage systems.

#### External USB HDD
- Uses an internal SATA HDD connected through a USB-to-SATA bridge.
- Protocol: USB Mass Storage or USB Attached SCSI (UASP).
- Interface speed: Depends on the USB generation and bridge controller.
- Typical sequential transfer speed: ~100–250 MB/s for modern external HDDs.
